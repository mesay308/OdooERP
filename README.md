# Addis Tech PLC — Odoo ERP Overview & Implementation Guide

Mobile-first, interactive HTML presentation and comprehensive implementation guide for **Odoo ERP** by **Addis Tech PLC** (Addis Ababa, Ethiopia).

## Pages Included

- **`index.html` (Default — Visual Presentation):** Simplified, visual-oriented mobile presentation with SVG architecture diagrams, infographics, Odoo ERP brand zone (Sections 4–6), interactive module explorer, and industry selector.
- **`addis_tech_odoo_guide.html` (Main Document — Full Guide):** Complete, verbatim 11-section document brochure with interactive module accordions, industry tabs, and implementation methodology.

## Deployment on Vercel

This repository is pre-configured for zero-build static deployment on [Vercel](https://vercel.com):

1. Import `https://github.com/mesay308/OdooERP` in Vercel.
2. Framework Preset: **Other** (Static HTML).
3. Click **Deploy**.
